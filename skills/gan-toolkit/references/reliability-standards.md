# GaN 可靠性标准与认证路线

> 标准号与条款以官方最新版本为准，本表为工程速查。正式送检前必须核对原文。

## 二、典型可靠性测试项与 GaN 关注点

| 测试 | 标准 | 应力条件 | GaN 特别关注 |
|---|---|---|---|
| HTRB / 高温反偏 | JS-002 | 高温 + 高 Vds（常 80% BV） | 缓冲层陷阱累积，动态 Rds(on) 抬升 |
| HTGB 高温栅偏 | JS-002 / B101 | 高温 + 栅偏压 | p-GaN 栅退化、阈值漂移 |
| HTGR 高温栅反偏 | JS-001 | 高温 + 栅反压 | 负压容限、界面态 |
| H3TRB 高湿高温反偏 | JS-002 | 85/85% RH + 偏压 | 塑封与钝化层、离子迁移 |
| 温度循环 TC | JESD22-A104 | -55~125 °C | 封装翘曲、分层、键合疲劳 |
| 功率循环 PC | JESD22-B | 功率循环 | 焊层疲劳（银烧结/铜线/铜夹） |
| 瞬态热循环 TCT | JESD22-A104 变体 | 快速温度阶跃 | 局部应力、栅极热退化 |
| 雪崩能力 | JESD24-2 | 重复雪崩 | GaN 动态雪崩耐受远低于静态 E_as |
| 短路耐受 | JESD24-3 | 规定 Vds 下短路 | GaN 极弱项，1–3 µs 量级 |
| 栅极寿命 | JEP217 | 组合应力外推 | 活化能与失效机理确认 |
| 湿敏 MSL | J-STD-033 | — | GaN 栅极静电敏感，需防静电包装 |

## 三、认证路线（按目标市场）

### 消费电子 / 快充（最简路径）
1. JEDEC 基线：HTRB + HTGB + HTGR + TC + PC + 湿热
2. 安规：IEC 62368-1 / UL
3. EMC：EN 55032 + 谐波
4. 温度范围：一般 -0~105 °C 环境（商业级）

### 工业 / 服务器电源
1. JEDEC 基线（同上）+ 高压 HTRB（900V 段必测）
2. 适用 IEC 61000-4-x 系列（抗扰度）
3. 需提供 MTBF 估计（Telcordia/IEC 62380）与寿命外推依据
4. 客户特殊要求（如 NVIDIA/OCP 规范）需单列差距分析

### 汽车（OBC / DC-DC）
1. **AEC-Q101 + AEC-Q102** 双认证（GaN 必须查 Q102）
2. 零缺陷（PPAP、MSA、追溯体系）
3. 供应商审核（VDA 6.3、过程审核）
4. 变更控制（PCN 流程、原材料冻结）
5. 100% 老化筛选（HTOL、功率循环、随机应力）
6. 长周期供货承诺（15 年）

### 光伏 / 储能
1. JEDEC 基线 + 长时间老化
2. IEC 62116（并网防孤岛）属系统级
3. 认证机构常加做 1000h/2000h 连续运行
4. 户外温度范围 -40~+85/105 °C，湿热要求高
